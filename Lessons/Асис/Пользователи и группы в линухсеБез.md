# ИМЯ ПОЛЬЗОВАТЕЛЯ

для Linux имя пользователя является лишь **сведением** (или: обозначением),  
который необходим нам, а не системе. Система  
идентифицирует пользователя по уникальному параметру **uid**  
(user identifier), который, как правило, задается автоматически  
при создании.

Данный параметр определяет конкретного пользователя, а  
также права, которыми он  
обладает в системе.

Чтобы узнать uid **текущего** пользователя, необходимо  
прописать команду `id`. Если после команды `id` указать имя  
пользователя, выведется информация  
по указанному пользователю.

text

clown@linux:~$ id  
uid=1000(clown) gid=1000(clown) groups=1000(clown),27(sudo)
# Типы пользователей

**root** — суперпользователь, **учётная запись** в Unix-подобных системах, владелец которой имеет право на выполнение **всех** операций без исключения. Присутствует в системе по умолчанию. **uid = 0**

**Системные пользователи** — **учётные записи**, которые есть у системных процессов для управления привилегиями и правами доступа к файлам и каталогам. Создаются системой автоматически. **uid от 100 до 999**

**Обычные пользователи** — учётные записи пользователей, **допущенных к управлению** системой. Создаются системным администратором. **uid от 1000 до 60000**
